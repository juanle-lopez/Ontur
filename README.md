# Ontur en datos

Página con la población de Ontur (Albacete) desde 1900 y los resultados de las elecciones generales (2008–2023) y municipales (2007–2023) en el municipio.

**Web:** https://juanle-lopez.github.io/ontur/

- `index.html`: la página (HTML, CSS y JavaScript con d3).
- `datos/`: los datos en CSV (población, votos por partido, participación y censo electoral).

Fuentes: censos y padrón del INE (vía foro-ciudad.com), resultados por municipio publicados por Público (escrutinio al 100 %) y censo electoral de la Oficina del Censo Electoral (vía telencuestas.com). Los concejales se calculan con la regla D'Hondt a partir de los votos.
